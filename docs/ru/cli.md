# CLI

`arca` — та же Arca в терминале: публикует файлы, вывод команд и черновики из `$EDITOR`. Шифрует так же, как браузер, и видит тот же список «Мои заметки».

## Установка

Из папки проекта:

```bash
npm run cli:install      # ставит команды arca и arca-shot
arca login               # адрес сервера + код доступа
```

Команды ставятся копией в папку Node (`/opt/homebrew/lib/node_modules/arca`), поэтому работают откуда угодно и не зависят от папки проекта. После обновления проекта повтори `npm run cli:install`.

`arca login` сохраняет настройки в `~/.config/arca/config.json` с правами `600`.

## Команды

| Команда | Что делает |
|---|---|
| `arca` | Открыть `$EDITOR`, после сохранения и выхода — ссылка |
| `arca note.md` | Опубликовать файл |
| `echo "текст" \| arca` | Опубликовать stdin |
| `arca get '<url>'` | Расшифровать заметку в stdout |
| `arca get '<url>' -o dir` | …и сохранить вложения в папку |
| `arca ls` | Мои заметки: ссылка, срок, заголовок (через табуляцию) |
| `arca rm '<url>'` | Удалить заметку |

⚠️ Бери ссылки в **одинарные кавычки**: zsh воспринимает `#` как спецсимвол.

## Флаги

| Флаг | Значение |
|---|---|
| `-a, --attach <file>` | Приложить файл, можно несколько раз |
| `-e, --expires <ttl>` | `1h`, `1d`, `1w`, `30d` (по умолчанию), `never` |
| `-b, --burn` | Сжечь после прочтения |
| `-t, --text` | Обычный текст вместо Markdown |
| `-l, --lang <id>` | Код с подсветкой: `auto`, `bash`, `python`, `javascript`, `json`, `xml`, `sql`, `diff`… |

Полный список языков — `arca -h`.

## Как выбирается формат

| Источник | Формат |
|---|---|
| Флаг `-t` | Обычный текст |
| Флаг `-l <язык>` | Код с этим языком |
| `.md` или stdin | Markdown |
| `.py`, `.sh`, `.html`, `.json`, `.diff`, `.log` и другие известные расширения | Код, язык по расширению |
| Остальные файлы | Обычный текст |

## Режим редактора

`arca` без аргументов открывает `$EDITOR`. Сохранил и вышел — заметка опубликована, ссылка в stdout.

Черновик живёт в `~/.local/state/arca/draft.md` (права `600`), пока заметка не опубликована. Закрыл терминал посреди набора — снова `arca`, и текст на месте. Если редактор завершился с ошибкой (например, `:cq` в vim), черновик сохраняется, но не публикуется.

```bash
export EDITOR=nvim             # или "zed --wait"
```

## Примеры

```bash
arca | pbcopy                                   # ссылка сразу в буфер
arca draft.md -e 1w                             # файл на неделю
git diff | arca -l diff -e 1d                   # дифф на день
journalctl -u app -n 200 | arca -l plaintext    # лог с номерами строк
arca report.md -a data.csv -a chart.png         # заметка с вложениями
echo "пароль от стенда" | arca -t -b            # одноразовая заметка
arca get '<url>' > note.md                      # заметку — в файл, например в Obsidian
```

## nvim

```vim
:w !arca                       " опубликовать текущий буфер
:r !arca get '<url>'           " вставить заметку под курсор
```

## Переменные окружения

| Переменная | Значение |
|---|---|
| `ARCA_URL` | Адрес сервера, перекрывает конфиг |
| `ARCA_CODE` | Код доступа, перекрывает конфиг |
| `EDITOR` | Редактор для режима редактора |

Переменные удобны для скриптов и ИИ-агентов: агент публикует результат через `arca` и возвращает ссылку.
