# Веб-интерфейс

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Редактор: текст, файлы, срок жизни, «Мои заметки» |
| `/n/<id>#<ключ>` | Просмотр заметки. Вход не нужен |
| `/login` | Вход по коду доступа |

![Редактор Arca](/assets/screens/editor-light.webp)

## Форматы

Формат выбирается справа над полем ввода.

| Формат | Для чего | Как показывается |
|---|---|---|
| **Markdown** | Тексты, планы, списки задач | Как на GitHub: заголовки, таблицы, чекбоксы, блоки кода с подсветкой |
| **Код** | Скрипты, конфиги, логи, вёрстка | Подсветка синтаксиса, номера строк, широкая страница |
| **Обычный текст** | Всё остальное | Как есть, моноширинным шрифтом |

Для кода язык определяется автоматически или выбирается из списка: Bash, Python, JavaScript, TypeScript, JSON, HTML/XML, CSS, SQL, YAML, Diff, Go, Rust, Java, PHP, C, C++, Dockerfile, Nginx, INI/TOML и другие.

💡 Код только **показывается**: HTML не рендерится, скрипты не запускаются. Можно спокойно делиться вёрсткой или подозрительным фрагментом из исследования.

Вкладка **«Предпросмотр»** показывает заметку так, как её увидит читатель.

## Файлы

- До 10 файлов по 50 МБ
- Перетащи на страницу, вставь из буфера (`⌘V`) или выбери в диалоге
- Файлы шифруются так же, как текст. Читатель скачивает их кнопкой, браузер ничего не открывает и не исполняет

Если в буфере одновременно текст и файл, вставится текст.

## Срок жизни

| Вариант | Когда удалится |
|---|---|
| 1 час, 1 день, 1 неделя | Через указанное время |
| **30 дней** | По умолчанию |
| Бессрочно | Только вручную |

В заметке и в списке виден счётчик: «🔥 12 дней».

## Сжечь после прочтения

Включи переключатель 🔥 перед публикацией. Заметку можно открыть **один раз**: по кнопке «Открыть заметку». Подробно — в разделе [Как это устроено](/docs/how-it-works/#одноразовые-заметки).

![Одноразовая заметка](/assets/screens/burn-light.webp)

## Черновик

Текст сохраняется в браузере на лету. Закрыл вкладку — при следующем открытии черновик на месте. После публикации черновик очищается.

## Заметка по ссылке

![Просмотр заметки](/assets/screens/note-light.webp)

Иконки справа вверху:

| Иконка | Действие |
|---|---|
| ✏️ | Править. Видна только автору, ссылка не меняется. Одноразовые заметки править нельзя |
| Поделиться | На телефоне — системное меню, на компьютере — копирует ссылку |
| Копировать | Текст заметки в буфер |
| Скачать | Текст в файл: `.md`, `.txt` или расширение языка кода |

## Мои заметки

Список живых заметок справа. Он общий для всех браузеров и CLI с тем же кодом доступа. Отсюда же заметку можно удалить, не дожидаясь срока.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `⌘↵` / `Ctrl+Enter` | Создать ссылку и скопировать её |
| `⌘V` | Вставить файл или скриншот из буфера |

## Тема

Светлая и тёмная, переключаются вместе с системной.
