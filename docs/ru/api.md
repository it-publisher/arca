# API

HTTP API, которым пользуются браузер и CLI. Всё содержимое, которое через него проходит, — шифротекст в base64url. Шифрует и расшифровывает только клиент.

Готовый клиент со всей криптографией — `shared/client.js`. Он работает и в браузере, и в Node, поэтому для своих скриптов проще импортировать его, чем собирать запросы вручную.

## Авторизация

```text
Authorization: Bearer <токен>
```

Передаётся **токен**, а не код доступа: ключ истории на сервер не уходит.

## Методы

| Метод | Путь | Токен | Что делает |
|---|---|---|---|
| `GET` | `/api/me` | ✅ | Проверить токен → `{ user }` |
| `POST` | `/api/files` | ✅ | Загрузить зашифрованный файл (`application/octet-stream`) → `{ id }` |
| `POST` | `/api/notes` | ✅ | Создать заметку → `{ id }` |
| `GET` | `/api/notes` | ✅ | Мои живые заметки с зашифрованными записями истории |
| `GET` | `/api/notes/:id` | — | Заметка. Для одноразовой — только флаг, без содержимого |
| `POST` | `/api/notes/:id/open` | — | Открыть одноразовую заметку и сжечь её |
| `PUT` | `/api/notes/:id` | ✅ | Изменить свою заметку (кроме одноразовых) |
| `DELETE` | `/api/notes/:id` | ✅ | Удалить свою заметку |
| `GET` | `/api/files/:id` | — | Скачать зашифрованный файл |

## Создание заметки

```json
{
  "payload": "<base64url шифротекст заметки>",
  "ownerEntry": "<base64url запись для «Моих заметок»>",
  "files": ["<id файла>"],
  "expiresIn": 2592000,
  "burnAfterRead": false
}
```

| Поле | Значение |
|---|---|
| `payload` | `iv (12 байт) ‖ шифротекст ‖ тег (16 байт)`, AES-256-GCM |
| `ownerEntry` | Ключ заметки и заголовок, зашифрованные ключом истории |
| `files` | Id файлов, загруженных через `POST /api/files` |
| `expiresIn` | Секунды: `3600`, `86400`, `604800`, `2592000` или `null` (бессрочно) |
| `burnAfterRead` | `true` — сжечь после прочтения |

## Пример на Node

```javascript
import { publishNote } from './shared/client.js';

const { path } = await publishNote({
  baseUrl: 'https://arca.example.com',
  accessCode: process.env.ARCA_CODE,
  text: '# Отчёт\n\nГотово.',
  format: 'md',
});
console.log(`https://arca.example.com${path}`);
```

## Лимиты

| Что | Лимит |
|---|---|
| Текст заметки | 1 МБ |
| Файл | 50 МБ |
| Файлов в заметке | 10 |

## Ошибки

| Код | Когда |
|---|---|
| `400` | Неверный формат запроса |
| `401` | Нет токена или он неверный |
| `404` | Заметки нет, она сгорела, истекла или принадлежит другому |
| `411` | Загрузка файла без `Content-Length` |
| `413` | Превышен лимит размера |
