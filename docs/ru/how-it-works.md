# Как это устроено

Arca построена так, чтобы сервер ничего не знал о содержимом заметок. Ниже — что происходит при публикации и почему администратор сервера не может прочитать текст.

## Шифрование заметки

1. Клиент (браузер или CLI) генерирует случайный ключ **AES-256-GCM**
2. Текст и каждый файл шифруются на клиенте
3. На сервер уходят только зашифрованные байты
4. Ключ кладётся в ссылку после `#`:

```text
https://arca.example.com/n/q3Zr8xKpL0a#hR7…Vb2
                           ^^^^^^^^^^^ ^^^^^^^
                           id          ключ
```

Часть ссылки после `#` (фрагмент) браузер **никогда не отправляет на сервер**. Сервер получает запрос `/n/q3Zr8xKpL0a`, отдаёт шифротекст, а расшифровывает его браузер читателя ключом из ссылки.

Следствие: даже с полным доступом к VPS и базе прочитать заметки нельзя. Обратная сторона тоже важна:

⚠️ Потерял ссылку — потерял заметку. Восстановить ключ не может никто.

## Код доступа

Код доступа — одна строка на человека: `<токен>.<ключ истории>`.

| Часть | Где хранится | Зачем |
|---|---|---|
| Токен | На сервере (`ARCA_USERS`) и на устройстве | Право создавать, менять и удалять свои заметки |
| Ключ истории | **Только на устройстве** | Расшифровка списка «Мои заметки» |

На сервер отправляется только токен. Ключ истории остаётся у тебя.

## «Мои заметки» на всех устройствах

При публикации клиент шифрует ключом истории маленькую запись: «ключ заметки + заголовок». Она хранится на сервере рядом с заметкой.

Любое устройство с тем же кодом доступа получает эти записи и расшифровывает их локально. Так список заметок одинаковый в браузере на ноутбуке, на телефоне и в CLI, а сервер не видит ни заголовков, ни ключей.

Заметка сгорела — запись исчезает вместе с ней.

## Что видит сервер

| Видит | Не видит |
|---|---|
| Размер заметки и файлов | Текст, заголовок, имена файлов |
| Время создания и срок жизни | Ключ заметки |
| Какой пользователь создал заметку | Ключ истории |
| Флаг «сжечь после прочтения» | Кто открыл ссылку (access-лог в Caddy выключен) |

## Одноразовые заметки

Заметка с флагом «Сжечь после прочтения» сгорает в момент нажатия кнопки **«Открыть заметку»**, а не при переходе по ссылке:

1. По ссылке открывается заглушка, содержимое ещё не загружено. Превью в мессенджерах и сканеры ссылок заметку не сжигают: они не нажимают кнопок
2. Кнопка отправляет `POST`. Сервер в одной транзакции отдаёт шифротекст и стирает его из базы. Если двое нажмут одновременно, текст получит только один
3. Текст остаётся во вкладке читателя до перезагрузки
4. Вложения доступны ещё 10 минут, чтобы их успели скачать, затем удаляются

Неоткрытая одноразовая заметка живёт до конца выбранного срока.
