# Скриншоты на macOS

Нажимаешь горячую клавишу, выделяешь область экрана — и через секунду в буфере ссылка на зашифрованный скриншот. Esc отменяет съёмку.

Работает через `scripts/arca-shot.sh` и CLI, поэтому сначала нужен выполненный [`arca login`](/docs/cli/).

## Настройка

1. Открой «Быстрые команды» → **+** → действие **«Запустить скрипт оболочки»**
2. В текст скрипта вставь полный путь к `scripts/arca-shot.sh`, например:

   ```bash
   ~/code/arca/scripts/arca-shot.sh
   ```

3. Нажми **ⓘ** → **«Добавить быстрое сокращение клавиш»**, например `⌃⌥⌘A`
4. Настройки «Быстрых команд» → «Дополнения» → включи **«Разрешить запуск скриптов»**
5. При первом запуске macOS попросит доступ к **записи экрана** — разреши

## Что делает скрипт

1. `screencapture -i` — интерактивное выделение области
2. Скриншот публикуется через `arca` во временной папке, которая удаляется после работы
3. Ссылка копируется в буфер, приходит уведомление

## Срок жизни

По умолчанию — 30 дней. Чтобы изменить, задай переменную в настройках скрипта:

```bash
ARCA_SHOT_EXPIRES=1d ~/code/arca/scripts/arca-shot.sh
```

Допустимые значения: `1h`, `1d`, `1w`, `30d`, `never`.
