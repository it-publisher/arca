# Скриншоты на macOS

Нажимаешь горячую клавишу, выделяешь область экрана — и через секунду в буфере ссылка на зашифрованный скриншот. Esc отменяет съёмку.

## Подготовка

Из папки проекта:

```bash
npm run cli:install      # ставит команды arca и arca-shot
arca login               # если ещё не входил
which arca-shot          # запомни путь, он понадобится ниже
```

На Mac с Apple Silicon путь будет `/opt/homebrew/bin/arca-shot`, на Intel — `/usr/local/bin/arca-shot`.

## Настройка горячей клавиши

1. Открой «Быстрые команды» → **+** → действие **«Запустить скрипт оболочки»**
2. В текст скрипта вставь полный путь из `which arca-shot`, например `/opt/homebrew/bin/arca-shot`
3. ⚠️ Галочка **«Запустить от имени администратора»** должна быть **снята**
4. Нажми **ⓘ** → **«Добавить быстрое сокращение клавиш»**, например `⌃⌥⌘A`
5. Настройки «Быстрых команд» → «Дополнения» → включи **«Разрешить запуск скриптов»**
6. При первом запуске macOS попросит доступ к **записи экрана** — разреши

Остальные поля действия (оболочка, входные данные) можно не трогать.

## Что делает скрипт

1. `screencapture -i` — интерактивное выделение области
2. Скриншот публикуется через `arca` из временной папки, которая удаляется после работы
3. Ссылка копируется в буфер, приходит уведомление

## Срок жизни

По умолчанию — 30 дней. Чтобы изменить, задай переменную перед путём в тексте скрипта:

```bash
ARCA_SHOT_EXPIRES=1d /opt/homebrew/bin/arca-shot
```

Допустимые значения: `1h`, `1d`, `1w`, `30d`, `never`.

## Если не работает

| Что видишь | Причина | Что сделать |
|---|---|---|
| `Operation not permitted` | Указан путь к скрипту внутри проекта на «Рабочем столе», в «Документах» или «Загрузках». macOS не пускает туда «Быстрые команды» | Выполни `npm run cli:install` и укажи путь из `which arca-shot` |
| `command not found` | У «Быстрых команд» свой короткий `PATH` | Укажи полный путь, а не просто `arca-shot` |
| Уведомление «Не удалось загрузить» | Включён запуск от имени администратора или не выполнен `arca login` | Сними галочку, выполни `arca login` |
| Скриншот пустой или только обои | Нет доступа к записи экрана | «Системные настройки» → «Конфиденциальность и безопасность» → «Запись экрана» → включи «Быстрые команды» |
