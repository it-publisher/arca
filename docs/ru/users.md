# Пользователи и коды доступа

Писать в Arca могут только люди из списка на сервере. Читать — все, у кого есть ссылка. Регистрации нет по замыслу: это инструмент для тебя и пары доверенных людей, а не публичный сервис.

Пользователями управляет команда `arca-user` на сервере. Она ставится при [деплое](/docs/deploy/) (шаг 6).

## Команды

| Команда | Что делает |
|---|---|
| `arca-user add <имя>` | Создать пользователя и напечатать его код доступа |
| `arca-user reset <имя>` | Новый код вместо утёкшего или потерянного |
| `arca-user remove <имя>` | Отозвать доступ |
| `arca-user list` | Список пользователей |

Имя — латиница, цифры, `-` и `_`. Оно нужно только тебе, чтобы различать людей.

## Добавить человека

Со своего компьютера:

```bash
ssh arca arca-user add anna | pbcopy
```

| Часть | Что делает |
|---|---|
| `ssh arca` | Выполняет команду на сервере |
| `arca-user add anna` | Создаёт токен, дописывает `anna` в `/opt/arca/.env`, перезапускает Arca и печатает код доступа |
| `\| pbcopy` | Кладёт код в буфер обмена на твоём компьютере. На экран он не выводится |

Если Arca не запустится с новым списком, скрипт сам вернёт всё как было.

Передай код безопасно — например, одноразовой заметкой в самой Arca:

```bash
pbpaste | arca -t -b -e 1d | pbcopy
```

Человек открывает ссылку, копирует код и вводит его на странице входа и в `arca login`.

## Токен и код доступа

| | Токен | Код доступа |
|---|---|---|
| Вид | `Kx7…Qw` | `Kx7…Qw.hR7…Vb2` |
| Где | На сервере, в `ARCA_USERS` | Только у человека |
| Даёт | Право писать | Право писать + расшифровку «Моих заметок» |

Код доступа — это токен плюс случайный **ключ истории**. Ключ создаётся один раз, в момент выдачи кода, и на сервере не сохраняется.

## ⚠️ Код выдаётся один раз

Попроси человека сразу сохранить код в менеджере паролей. Восстановить его нельзя: ключа истории нет нигде, кроме самого кода.

Если код потерян, выдай новый:

```bash
ssh arca arca-user reset anna | pbcopy
```

- Ссылки на старые заметки продолжат работать и сгорят по сроку как обычно
- В «Моих заметках» они **не появятся**: новый код — новый ключ истории

## Код утёк

1. Пока старый код работает, удали им чувствительные заметки: в «Моих заметках» или `arca rm '<url>'`
2. Выдай новый код: `ssh arca arca-user reset anna | pbcopy`. Старый перестанет работать сразу
3. Передай новый код человеку

Ссылки, которые успели уйти в чужие руки, продолжат открываться до конца срока — поэтому шаг 1 важен.

## Отозвать доступ

```bash
ssh arca arca-user remove anna
```

Человек больше не сможет создавать заметки. Его уже отправленные ссылки продолжат работать до конца срока.
