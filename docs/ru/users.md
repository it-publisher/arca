# Пользователи и коды доступа

Писать в Arca могут только люди из списка на сервере. Читать — все, у кого есть ссылка. Регистрации нет по замыслу: это инструмент для тебя и пары доверенных людей, а не публичный сервис.

## Где хранятся пользователи

В `.env` на сервере, через запятую:

```ini
ARCA_USERS=me:<токен>,anna:<токен>,max:<токен>
```

- Имя — любое слово без `:` и `,`. Оно нужно только тебе, чтобы различать людей
- Токен — минимум 24 символа, генерируется `npm run -s token`

## Токен и код доступа

| | Токен | Код доступа |
|---|---|---|
| Вид | `Kx7…Qw` | `Kx7…Qw.hR7…Vb2` |
| Где | На сервере и внутри кода | Только у человека |
| Даёт | Право писать | Право писать + расшифровку «Моих заметок» |

Код доступа получается из токена добавлением случайного **ключа истории**. Этот ключ не попадает на сервер.

## Типовые задачи

| Задача | Как |
|---|---|
| Добавить человека | `npm run -s token` → дописать `name:<токен>` в `ARCA_USERS` → `systemctl restart arca` |
| Выдать код | Команда ниже, один раз на человека |
| Отозвать доступ | Удалить `name:<токен>` из `ARCA_USERS` → `systemctl restart arca` |
| Код утёк | Новый токен для этого человека + новый код доступа |

## Выдать код доступа

Команда берёт токен с сервера, превращает в код и кладёт в буфер. Токен не появляется на экране и не попадает в историю shell:

```bash
ssh arca "sed -nE 's/.*anna:([^,]+).*/\1/p' /opt/arca/.env" | npm run -s access-code | pbcopy
```

Передай код безопасно — например, одноразовой заметкой в самой Arca:

```bash
pbpaste | arca -t -b -e 1d | pbcopy
```

Человек открывает ссылку, копирует код и вводит его на странице входа и в `arca login`.

## ⚠️ Один код на человека

Генерируй код **один раз** и проси человека сохранить его в менеджере паролей. Каждый новый код — это новый ключ истории:

- Заметки, созданные со старым кодом, **не появятся** в списке «Мои заметки» (будут помечены как «созданы с другим кодом доступа»)
- Ссылки на них продолжат работать и сгорят по сроку как обычно

Если человек потерял код, выдай новый: старые ссылки останутся рабочими, просто не будут видны в его списке.

## Код утёк

1. Пока старый код работает, удали им чувствительные заметки: в «Моих заметках» или `arca rm '<url>'`
2. Сгенерируй новый токен и замени им старый в `ARCA_USERS`
3. `systemctl restart arca`
4. Выдай человеку новый код

Старый код перестанет давать доступ к серверу. Ссылки, которые успели уйти в чужие руки, продолжат открываться до конца срока — поэтому шаг 1 важен.
