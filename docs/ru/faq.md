# FAQ

## Есть ли публичный сервер, где можно попробовать?

Нет. Arca рассчитана на свой сервер: открытый анонимный инстанс с шифрованием невозможно модерировать. Попробовать локально можно за пять минут: [Быстрый старт](/docs/quickstart/).

## Чем Arca отличается от других pastebin?

Arca решает одну задачу: быстро и приватно поделиться заметкой, которая нужна прямо сейчас. Отличия от типичных pastebin:

- Шифрование на клиенте всегда, а не опционально
- Писать могут только свои, читать — все по ссылке
- Общий зашифрованный список «Моих заметок» в браузере и в терминале
- CLI и скриншот по горячей клавише
- Сервер на Node без внешних зависимостей

## Можно ли сделать открытую регистрацию?

Нет, и это осознанное решение. Arca — инструмент для себя и пары доверенных людей. Открытый сервис с шифрованием быстро становится хостингом для фишинга и малвари, а модерировать зашифрованное нельзя.

## Я потерял ссылку на заметку

Если у тебя есть код доступа, заметка есть в «Моих заметках» в браузере или в `arca ls`. Если нет — восстановить нельзя: ключ существует только в ссылке.

## Я потерял код доступа

Попроси администратора выдать новый. Старые ссылки продолжат работать, но в новом списке «Моих заметок» их не будет.

## Администратор сервера может прочитать мои заметки?

Нет. Он видит только зашифрованные байты, размеры, время создания и имя автора. Подробнее — [Безопасность](/docs/security/).

## Когда сгорает одноразовая заметка?

В момент нажатия кнопки «Открыть заметку», а не при переходе по ссылке. Подробнее — [Как это устроено](/docs/how-it-works/#одноразовые-заметки).

## Можно ли редактировать заметку?

Да, если ты автор: значок ✏️ на странице заметки. Ссылка не меняется. Одноразовые заметки редактировать нельзя.

## Почему нельзя открыть по http://IP?

Браузеры дают доступ к WebCrypto только в защищённом контексте: по HTTPS или на `localhost`. Без него шифрование не работает.

## Сколько ресурсов нужно серверу?

Очень мало: сервис занимает около 30 МБ памяти. Хватит самого дешёвого VPS. Место на диске зависит от файлов, которые вы загружаете.

## На каком языке интерфейс?

Пока только на русском.

## Можно ли подключить ИИ-агента?

Да, через CLI: агент вызывает `echo "<результат>" | arca` и возвращает ссылку. Для скриптов на Node есть готовый клиент — см. [API](/docs/api/).
