# Быстрый старт

Запустим Arca у себя на компьютере, создадим первую заметку и откроем её по ссылке. Это займёт около пяти минут. Чтобы делиться заметками с другими людьми, потом понадобится сервер: см. [Деплой на VPS](/docs/deploy/).

## Что нужно

- Node.js **22.13 или новее**: в нём есть встроенный `node:sqlite`, другой базы не требуется
- Git
- Браузер: подойдёт любой современный

Проверить версию Node:

```bash
node -v
```

## 1. Скачать и собрать

```bash
git clone https://github.com/it-publisher/arca.git
cd arca
npm install
npm run build
```

`npm install` ставит только инструменты сборки фронтенда. Самому серверу внешние пакеты не нужны.

## 2. Завести пользователя

Писать в Arca могут только пользователи из списка `ARCA_USERS`. Создадим токен и запишем его в `.env`:

```bash
npm run -s token                 # напечатает случайный токен
cp .env.example .env
```

Открой `.env` и замени `REPLACE_WITH_TOKEN` на полученный токен:

```ini
ARCA_USERS=me:Kx7…твой-токен…Qw
```

## 3. Запустить

```bash
npm start
```

Сервер слушает `http://127.0.0.1:3000`.

## 4. Получить код доступа и войти

Токен — это право писать на сервер. Для входа нужен **код доступа**: токен плюс ключ шифрования твоего списка заметок. В новом окне терминала:

```bash
echo "<токен>" | npm run -s access-code
```

Открой `http://127.0.0.1:3000`, вставь код в поле «Код доступа». Браузер запомнит его.

⚠️ Сохрани код в менеджере паролей. Он нужен на каждом новом устройстве, и восстановить его нельзя: ключ истории есть только в коде. Подробнее: [Пользователи и коды доступа](/docs/users/).

## 5. Первая заметка

1. Напиши текст, например `# Привет, Arca`
2. Нажми **«Создать ссылку»** или `⌘↵`
3. Ссылка уже в буфере обмена: открой её в другом браузере или в режиме инкогнито

Заметка расшифруется прямо в браузере. Сервер хранит только шифротекст.
